# Evaluation of Sycophancy in SmolLM Family Models

This project compares sycophantic behavior across three models:
1. **SmolLM-135M-Instruct (v1)** - Baseline
2. **SmolLM2-135M-Instruct (v2)** - Generational comparison
3. **SmolLM2-1.7B-Instruct (v2)** - Scaling comparison

## Methodology
We use a hybrid approach of logit analysis and semantic judging using **JEV (TypeSafe AI)**.
