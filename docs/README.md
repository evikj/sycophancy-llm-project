# docs/

Овде оди целосниот извештај од експериментите, на македонски:
методологија, резултати, графикони, дискусија и заклучок.

Овој README.md (на англиски) и коментарите во кодот се одделни од
извештајот - тие служат за техничка документација на репозиториумот на
GitHub. Извештајот е научниот/академскиот текст.

Предлог: `docs/izvestaj.md` или `docs/izvestaj.pdf`.
